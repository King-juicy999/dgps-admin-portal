# DGPS Admin Portal

Frontend for the Diadem Golden Pearl Schools admin portal.

Built with plain HTML, CSS, and JavaScript. No frameworks or dependencies.

## Structure

- `index.html` — full portal (login + dashboard)
- `static/css/admin.css` — all styles
- `static/js/admin.js` — navigation, mock auth, AI assistant interactions
